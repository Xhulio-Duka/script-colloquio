# Posts · JSONPlaceholder + SWR

App React (Vite + TypeScript + pnpm) che carica i post da
[JSONPlaceholder](https://jsonplaceholder.typicode.com/posts) con **SWR** e li
renderizza uno a uno con `.map()`.
